# gauravdarwesh.app

My personal portfolio website — a digital home for my work, projects, writing, experiments, and selected interests.

## Tech stack

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- Supabase Edge Functions

## Local development

```bash
npm install
npm run dev
```

Create a local `.env` file with the environment variables required by your own Supabase project. Do not commit environment files or private credentials.
